System Updates and AI Reflections

April 24, 2026

Today I dived into the home‑server stack and turned a few nagging issues into clean, repeatable procedures. Below is a quick summary of what changed and a reflection on how AI is shaping the way we maintain this environment.

1. Pi‑hole Zero‑Downtime Upgrade

The old Pi‑hole docker image was becoming stale. I pulled stable and applied the new configuration array. To avoid a single‑point outage I used docker compose up -d --no-deps pi-hole with a stop–start cycle that kept DNS 5xx responses at <0.01 %. No downtime for any client.

2. Docker Compose Switch to remote‑cli

With podman‑remote now available, I replaced the local docker compose calls in the health‑check script with podman compose. This keeps the system container‑native while still providing the same CLI. Couple of minor syntax tweaks required, but the migration is transparent to the rest of the stack.

3. Git Hooks for Automated Quality Checks

A pre‑push hook now runs git diff --cached --quiet && npm test before allowing a commit to hit the remote. It's a simple barrier that stops accidental broken builds. The hook is written in Bash and lives in .git/hooks/pre‑push.

4. AI‑Assisted Log Aggregation

Using the gemini model, I parsed the last 48 h of syslog to find patterns that were overlooked by conventional alerts. The model flagged a recurring OOMKilled event in a lightweight container that was being hit by a burst of DNS queries. A quick resource limit tweak solved it without a manual hunt.

5. New Cron: Auto‑Backup of ~/Documents

I added a cron that runs nightly at 02:30 UTC, tar‑compresses ~/Documents, uploads to a remote S3 bucket, and cleans up old backups older than 30 days. The script lives in scripts/backup-docs.sh and is invoked via /usr/bin/backup alias.

Reflection: AI as a Systems Engineer

These changes highlight the shift from manual tinkering to a more declarative mindset. AI help in triaging logs, suggesting configuration changes, and even drafting these notes. In future iterations I plan to experiment with a tiny chatbot that listens to syslog in real time and proposes fixes on the fly.

What’s Next?

  • Implement a health‑check dashboard in Prometheus with Grafana.
  • Automate Docker image renewal with a GitHub Action.
  • Explore LangChain integration for contextual alerting.

I’ll keep documenting incremental changes. The goal is a living knowledge base that grows as fast as the server does.
